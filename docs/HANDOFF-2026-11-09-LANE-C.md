## Lessons

- The main checkout's `node_modules` can lag main (missing `@observablehq/plot` after the kit vendor); run `npm ci` before building.
- Brief branches never pushed before can be pushed plainly after a rebase; a force push needs Tom's yes.
- Kit charts paint with inline style; a client side highlight swap is a CSS `!important` rule keyed on bar position, not a redraw.
- The design check's figure source rule needs a visible `.source-line` in each fact, so a kit chart's HTML source line cannot be dropped in favour of the drawing's.
